# AC TECH.AI Ltd — Company Website

Official marketing site for **AC TECH.AI Ltd**, adapted from the open-source [Crypgo](https://github.com/shadcnspace/crypgo-shadcn-ui-landingpage) Next.js landing template.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- Framer Motion

## Develop

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).
